# JobCardBook promo video (Nepali, 20 s / 15 s)

Everything for the ad lives in this `ad/` folder. Nothing here touches `site/` or the app,
and nothing connects to a database. **All data on screen is dummy** (डेमो वर्कशप, राम बहादुर,
`98XXXXXXXX`, Model X/Y, रु 5,000 / 1,000 / 800).

## Output (`ad/out/`)

| File | Format |
|---|---|
| `jobcardbook_20s_vertical.mp4` | 1080×1920, 30 fps, 20 s, music + on-screen text |
| `jobcardbook_20s_horizontal.mp4` | 1920×1080, 30 fps, 20 s |
| `jobcardbook_15s_vertical.mp4` | 1080×1920, 15 s cut (no reminders/reports scene) |
| `*_voice.mp4` | same three videos with the Nepali voice, music ducked under it |
| `thumbnail.png` | 1080×1920 |

All MP4s are H.264 (yuv420p) + AAC 48 kHz, loudness about −14 LUFS, peaks below −1 dBFS.
`music_20s.wav` / `music_15s.wav` are the music beds (music + UI sounds, no voice).

## How it is made

| File | What it does |
|---|---|
| `timeline.js` | Scene start/end times for each cut and the sound-effect cue list. Shared by picture and sound. |
| `index.html` | The whole animation. Every frame is a pure function of time (`renderFrame(t)`), no CSS animations. |
| `render.js` | Opens `index.html` in headless Chromium (Playwright), steps through frames, pipes PNGs to ffmpeg. |
| `music.py` | Synthesises the music and sound effects from scratch with numpy/scipy. |
| `voice.py` | Makes the voice with eSpeak NG from `voiceover.txt`, ducks the music, masters to −14 LUFS. |
| `build.sh` | Runs all of the above and writes `out/`. |

### Re-render

Needs: Node + Playwright with Chromium, ffmpeg, Python 3 with `numpy scipy pyloudnorm`,
the font **Noto Sans Devanagari** (and Noto Sans), and optionally `espeak-ng` for the voice.

```bash
pip install numpy scipy pyloudnorm
```

```bash
sudo apt-get install -y ffmpeg espeak-ng fonts-noto-core
```

```bash
./build.sh
```

`./build.sh audio` rebuilds only the sound. Intermediate files go to `build/` (git-ignored).

Preview in a browser: open `index.html?layout=v&cut=20&play=1` (or `layout=h`, `cut=15`).
A single still: `node render.js still 20 v 9.2 frame.png`.

## Changing things

- **Text on screen** – edit the `<div class="cap" id="cap1…cap5">` blocks and `#endHead`, `#url`,
  `.badge` in `index.html`. Each word is its own `<span>`; `class="hl"` gives the gradient highlight.
  Keep captions to 6–8 words. The text inside the phone is in the `<div class="view">` blocks.
- **Colours** – CSS variables at the top of `index.html` (`--navy`, `--indigo`, `--violet`, `--pink`),
  plus the blob colours in the "background blobs" line of the script.
- **Layout / sizes** – the `LAY` object in `index.html` (`v` = vertical, `h` = horizontal): caption box,
  font size, phone position and scale.
- **Timing** – `timeline.js`. Scene boundaries sit on the beat (0.5 s at 120 BPM); keep them on
  multiples of 0.5 s so the music still lines up. Add a new cut by adding an entry to `cuts`.
- **Music** – in `music.py`: `BPM`, the chord loop `LOOP`, the melody `MOTIF`, the madal pattern
  `MADAL`, and the gain numbers in `build()`. Sound-effect cue times come from `timeline.js`.
- **Voice** – edit `voiceover.txt` (the `[start–end s]` windows are read by `voice.py`).
  Speed, pitch and ducking depth are constants at the top of `voice.py`.

## Voice: engine and licence

The voiced versions use **eSpeak NG 1.51**, voice `ne` (Nepali), fully offline.
eSpeak NG is free software under GPL-3.0-or-later; the licence covers the program, not the audio
it produces, so the generated speech can be used commercially.

eSpeak is a robotic, formant-style voice. It is fine as a guide track, but for a paid campaign
a human Nepali voice will sound much better. To swap it in: record the lines in `voiceover.txt`,
save as `build/voice_20.wav` (48 kHz, mono, lines placed at their times), then

```bash
python3 voice.py 20 --mix-only
```

and re-run the mux step of `build.sh`. The no-voice versions are complete on their own.

## Music: ownership

The music and every sound effect are generated by `music.py` from sine waves, sawtooth waves,
noise and a Karplus-Strong plucked string. No samples, loops or third-party recordings are used,
so there is nothing to license. 120 BPM, D major pentatonic, soft four-on-the-floor kick and hats,
a madal-style hand-drum pattern, warm pad chords, a plucked hook, a rising whoosh into each scene,
pops on UI elements and a clean hit on the final logo.

## Brand and data safety

- No real customer, dealer, vehicle-brand or price data appears anywhere.
- The reminder bubble is a generic green chat bubble and the export icon a generic "XLSX" sheet,
  so no third-party logos or brand names are shown. The only brand on screen is JobCardBook.
- No people, faces or stock footage; only UI, icons, text and motion graphics.
- Fonts: Noto Sans Devanagari and Noto Sans (SIL Open Font License).
